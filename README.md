# Morphology Trainer

A React/Vite app for practising English morphology.

Students:
1. classify each word as simple or complex;
2. select every affix;
3. classify each affix as derivational or inflectional.

The app includes 180 questions, category filters, explanations, scoring, saved history, and GitHub Pages deployment.

## Run locally

```bat
npm.cmd install
npm.cmd run dev
```

## Build

```bat
npm.cmd run build
```

GitHub Pages base path:

